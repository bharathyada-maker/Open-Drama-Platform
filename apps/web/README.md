# Open Drama Platform — Web Client

The official web frontend for **Open Drama Platform**, built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

## 🌐 Live Global Platform

The live web application is hosted and accessible globally at:

👉 **[https://bharathyada-maker.github.io/Open-Drama-Platform/](https://bharathyada-maker.github.io/Open-Drama-Platform/)**

---

## 🚀 Quick Start (Development)

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build
```
